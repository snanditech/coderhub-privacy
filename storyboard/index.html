StoryBoard Privacy Policy

App: StoryBoard – Story Planner (com.coderhub.storyboard) · Developer: CoderHub26 · Effective: 7 November 2026

Summary

StoryBoard is a story planner for writers: chapters, scenes, characters, places, a timeline and continuity checks. Everything you write stays on your device. The developer does not run a server for StoryBoard, does not receive your stories, and does not sell or share your data. StoryBoard has no accounts, no ads, no analytics, no tracking and no third-party SDKs.

What StoryBoard stores on your device

  • Your library. Stories, chapters, scene titles, synopses, drafts, characters, locations, timeline events, continuity overrides and your settings are saved as one file in the app's private storage. A previous copy of that file is kept so the app can recover after a damaged save.
  • Revision snapshots. Saved snapshots of scene drafts are part of that file. Autosave and manual snapshots are capped per scene.
  • Writing goal and streak. The number of words you added each day, and your daily word goal, are stored in the same file so the streak can be shown. Only word counts are kept, not the text of each day's writing.

Files you choose to save

StoryBoard writes files only where you choose, with Android's system file picker:

  • Manuscript exports. Markdown, plain text or PDF files of a story in the reading order you chose. You can also copy the text to the clipboard.
  • Project backups. A JSON file of one story, including drafts, revisions, cast, places, timeline and overrides. You can restore it later, on this device or another.

Once a file is saved, it is yours. StoryBoard does not upload it. If you save a file to a cloud app such as Google Drive, that app handles the upload under its own terms.

Permissions

StoryBoard requests no Android permissions. It has no network access, no camera, microphone, location, contacts or storage permission. Files are read and written only through the system file picker.

Android cloud backup

Android's automatic cloud backup is turned off for StoryBoard, so your library file is not copied to your Google account by the system. Use a project backup if you want a copy outside the device.

Data deletion

Deleting a story in StoryBoard removes it from the library file on this device. Uninstalling the app removes its private data. Backup and export files you saved are yours; delete them in your file manager. The developer holds no copy of your data, so there is nothing to request from us.

Children

StoryBoard is not designed for children under 13 and does not knowingly collect personal information from anyone.
